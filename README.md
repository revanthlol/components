# UI Components & Interaction Vault

A curated collection of bespoke UI components, interactive web prototypes, animation playgrounds, and motion patterns.

---

| **[`malnadu-menu/`](./malnadu-menu)** | HTML / CSS / JS | Super-hover restaurant menu with smooth preview transitions |

---

## 🛠️ Tech Stack Highlights
* **Frameworks:** React 18/19, Next.js, Vanilla TypeScript/JavaScript
* **Animation & Motion:** CSS Keyframes, GSAP ScrollTrigger, Simplex Noise, Framer Motion
* **Styling:** Tailwind CSS, PostCSS, Modern CSS Grid & Flexbox

---

## 🚀 Usage
Each subfolder contains its own self-contained source code, demos, or component files. You can drop any component directly into modern React/Vite/Next.js projects or open the standalone `.html` prototypes directly in any browser.
