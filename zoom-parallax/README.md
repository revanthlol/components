# Zoom parallax preview

```bash
npm install
npm run dev
```

Opens http://localhost:5173. Scroll down.

- Component: `src/components/ui/zoom-parallax.tsx`
- Demo: `src/components/ui/demo.tsx` (Lenis smooth scroll + 7 images)
- Images are the 21st.dev CDN URLs from the original demo. Swap the `src` values in `demo.tsx` for your own.
- Dark theme is set by `class="dark"` on `<html>` in `index.html`; remove it for light.
